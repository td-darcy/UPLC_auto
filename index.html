MassLynx report parser

Drop MassLynx / OpenLynx PDF reports to get retention time, area and ESI+ m/z for each peak. v11: one section per peak table

Load demo data with many peaks

Each peak table in the report (TAC, 254 nm, ELSD and so on) is shown separately. Tick Ignore to leave a peak out (noise, solvent front); the rest of that table is rescaled so Area % sums to 100, and Copy and CSV export only the kept peaks. ESI+ m/z is the tallest labelled ion in the spectrum matching the peak's retention time; other labelled ions follow it.
